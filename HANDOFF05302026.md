## 4. Key Decisions & Rationale

| Decision | Why |
|----------|-----|
| CSS vars keep `sangam-*` prefix | 100+ references across components + Tailwind config; renaming risks regressions with zero user benefit |
| localStorage keys keep `sangam_*` prefix | Changing would wipe all existing user data (auth tokens, preferences, cached state) |
| Firebase project ID stays `ethnicity-app` | Firebase doesn't allow project renames; no user-facing impact |
| Two-commit rebrand strategy | First pass for bulk changes, second pass for audit cleanup — maintains clean git history |
| DNSSEC disabled on enovoapp.com | IONOS DNSSEC is incompatible with Firebase's ACME SSL challenge; required for HTTPS to work |
| Build/deploy always from Mac | Rollup needs platform-specific binaries; Linux sandbox has macOS binaries from user's npm install |

## 5. Gotchas & Constraints

1. **Cannot `npm run build` in Cowork sandbox.** Rollup crashes with platform binary mismatch. All builds and deploys must happen on the user's Mac. You can still read, edit, grep, and run TypeScript checks (`npx tsc --noEmit`) in the sandbox.

2. **The folder is named `ethniCity_03_19_2026`** — this is the workspace mount point. Don't rename it.

3. **The repo is named `sangam-pwa-v2`** — GitHub repo name. Cosmetic only.

4. **Aurora design system** uses Tailwind utility classes prefixed with `aurora-` (e.g., `bg-aurora-surface`, `text-aurora-indigo`). This is Tailwind v4 (CSS-first) — these classes and their `--color-sangam-*` CSS variables are defined in `src/index.css` (there is **no** `tailwind.config.ts`). The theme constants in `src/constants/theme.ts` are the source of truth for color values.

5. **Firebase config** is in `src/constants/config.ts`, with the initialized Firebase app/services in `src/services/firebase.ts` (there is **no** `src/config.ts`). Firestore rules (`firestore.rules`), indexes (`firestore.indexes.json`), and Cloud Functions (`functions/`) live in the project root.

6. **Git credentials:** User recently regenerated their GitHub Personal Access Token. If push/pull fails with auth errors, they need to update their macOS Keychain credential (`git credential-osxkeychain erase`).

7. **Always update `hand_off_note_04_16.md`** at the end of every session with what was done, decisions made, and next steps.
